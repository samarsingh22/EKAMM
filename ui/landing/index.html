02 — EVIDENCE

Nothing is lost,
because nothing is parsed first.

A SHA-256 and a UUIDv7 are computed over the raw bytes and written append-only to Bronze before any parser runs. The commit point is the fsync — only then is the event acknowledged. The original stands on its own as evidence.

bronze · append-only SHA-256UUIDv7 gzip NDJSON
03 — ONE SCHEMA

Fourteen packs
become one shape.

Format sniffed, engine selected, fields extracted, then mapped into OCSF — Network Activity, HTTP, DNS and Detection Finding, with ECS and Splunk CIM crosswalks. Vendor fields with no OCSF home are kept, never dropped. One detection rule now works everywhere.

40014002 40032004 + ECS · Splunk CIM
04 — PROOF

And all of it
is provable.

Event hashes become leaves in a Merkle tree. Roots are chained and Ed25519-signed. A tampered byte anywhere in a day of traffic is located to the exact event by walking a handful of hashes — the cryptographic core of a blockchain, without the consensus layer that cannot work in a single-operator air-gap.

System architecture

Four zones, one direction
of travel.

Evidence is committed in Zone 2 and never rewritten. Everything downstream is derived, reproducible, and can be rebuilt from Bronze by replaying history.

Zone 1

Log sources

Perimeter network devices
  • Next-gen firewallsCisco ASA · PAN-OS 11.1 · FortiOS 7.4
  • IDS / IPSSuricata EVE — alert and flow
  • Network monitorZeek — conn · dns · http
  • Host & cloud edgeiptables · AWS VPC Flow Logs · NetFlow v9 / IPFIX
  • Extensible by designAny new device is one YAML file. No code, no rebuild, no restart.
Zone 2

Ingest & evidence

Capture layer — the commit point
  • ListenersSyslog UDP · TCP · TLS (514 / 6514) · HTTP + Splunk HEC · file tail · NetFlow / IPFIX
  • Bounded queueBackpressure, at-least-once. Memory never grows unbounded.
  • ★ Raw preservationSHA-256 + UUIDv7 computed before any parsing, appended to Bronze, then fsync.
  • Dead-letter queueUnparseable events divert visibly — never silently mis-parsed. Replayable once a parser exists.
  • Traceability anchorEvery normalised record carries event_uid + raw_hash back to its source bytes.
Zone 3

Processing core

The normalisation brain
  • Format snifferLayered detection, then strip the syslog envelope — PRI decode, facility, severity
  • Source registry14 YAML definitions, version-keyed. Hot reload validates before it swaps live.
  • Parse enginesjson · kv · csv · dissect · grok · cef · leef · tsv
  • ★ Drain3 template minerUnknown source → mined template → auto-drafted YAML parser, held for human review.
  • OCSF normaliser4001 Network · 4002 HTTP · 4003 DNS · 2004 Detection Finding, plus ECS and CIM crosswalks
  • Enrich & validateGeoIP · threat IOC · MITRE ATT&CK · asset zone — all offline. Then schema conformance and completeness.
Zone 4

Trust & output

Integrity · storage · consumers
  • ★ Integrity ledgerMerkle tree over event hashes → chained roots → Ed25519 signed. O(log n) proof to the exact event.
  • Bronze — evidenceRaw bytes + hash, immutable, partitioned by ingest date
  • Silver — analyticsParquet + ZSTD columnar, by event date and source
  • Query layerDuckDB (zero-infra) · ClickHouse at scale
  • ConsumersSIEM (OpenSearch, Splunk HEC) · data lake (Iceberg / MinIO) · ML anomaly and template drift

Built for India's critical information
infrastructure — not for someone

Per-device parser development is the largest hidden cost in SOC operations, and the one that breaks on every firmware update. One schema replaces a parser per device.
